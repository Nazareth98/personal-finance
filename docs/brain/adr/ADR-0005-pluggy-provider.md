# ADR 0005 — Adaptador Pluggy anterior (substituído)

Status: substituído pela ADR 0006 e pela migration `202611100011_meupluggy_personal.sql`.

Esta decisão histórica descrevia um adaptador comercial Pluggy com widget. Esse fluxo foi removido do produto: o widget, client frontend e RPCs comerciais foram removidos/revogados. Não usar esta ADR como instrução de implementação ativa. O produto atual permite somente Meu Pluggy pessoal do proprietário, sem acesso bancário aos demais usuários.
