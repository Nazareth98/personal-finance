# Categorização

Normalização Unicode NFD, remoção de diacríticos, minúsculas pt-BR, trim. Correspondência contains literal, inclusive asterisco. Menor priority vence; empate: termo maior e ID para determinismo. Apenas categoria é sugerida, nunca natureza financeira.

Sugestão é calculada na abertura da revisão com regras atuais. Mudança de categoria reconstrói opções de subcategoria; FK composta valida no banco. Aprovações anteriores não são reaplicadas nem sobrescritas. Regras pertencem exclusivamente ao workspace; não há seed histórico.
