# Fixtures MeuPluggy

Somente respostas sintéticas podem existir aqui. IDs, descrições, instituições e valores não correspondem a dados reais.

Ao adicionar uma fixture:

- mantenha apenas os campos necessários ao contrato testado;
- substitua identificadores, nomes, documentos e valores;
- nunca copie payloads brutos de produção;
- preserve casos de borda sem preservar a identidade da origem.
